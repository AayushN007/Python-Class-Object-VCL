# Python Class and Object - VCL

## Overview

This program demonstrates the basic concepts of Object-Oriented
Programming in Python using a simple video player simulation.

A class named `VCL` contains different methods representing
steps of a video application.

## Features

The program simulates:

- Opening the application
- Starting the video
- Starting the audio
- Increasing the volume
- Activating the progress bar
- Closing the application

A 2-second delay is added between each operation using the
`time` module.

## Concepts Covered

- Classes
- Objects
- Methods
- Object creation
- Method calling
- `time.sleep()`
- Basic Object-Oriented Programming
